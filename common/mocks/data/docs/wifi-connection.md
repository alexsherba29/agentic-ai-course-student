# Campus Wi-Fi connection guide

Use this guide when a user cannot join the campus Wi-Fi network or the connection keeps dropping.

The campus network is called "Campus-Secure". The "Campus-Guest" network is only for visitors and does not give access to internal services.

Steps to connect:

1. Forget the "Campus-Secure" network in the device's Wi-Fi settings.
2. Join "Campus-Secure" again and sign in with the university username and password.
3. When asked about a certificate, accept the certificate named "radius.example.edu".
4. If the device keeps dropping the connection, turn off "private Wi-Fi address" or "random MAC address" for this network only.

If many users in the same building report problems at once, check the service status page for Wi-Fi before trying device steps; it may be an outage.

If a single device still cannot connect, open a support ticket with the device type, the building and room, and the time of the problem.
