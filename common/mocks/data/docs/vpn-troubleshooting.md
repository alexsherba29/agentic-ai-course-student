# VPN connection troubleshooting

Use this guide when a user cannot connect to the company VPN, or the VPN connects and then drops.

Before you start, check the service status page for the VPN. If the VPN service shows an outage or maintenance, the problem is not on the user's computer: tell the user about the outage and do not ask them to change any settings.

If the VPN service is operational, ask the user to try these steps in order:

1. Disconnect from the VPN and quit the VPN client completely.
2. Check that the computer has a normal internet connection by opening any public website.
3. Restart the VPN client and sign in again with the company account.
4. If the client reports "certificate expired", restart the computer so that a new certificate can be installed.
5. If the connection still fails after a restart, collect the error message shown by the VPN client.

If none of these steps work, open a support ticket with the error message and the time of the last attempt.
