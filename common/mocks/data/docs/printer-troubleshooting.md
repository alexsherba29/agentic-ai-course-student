# Printer troubleshooting

Use this guide when a user cannot print to a campus printer.

1. Check that the user is printing to a printer whose name starts with "CAMPUS-". Personal printers are not supported.
2. Ask the user to check their print credit balance in the printing portal. Jobs are held, not printed, when credit runs out.
3. Ask the user to release the job at the printer by tapping their student or staff card on the reader.
4. If the job does not appear at the printer after two minutes, ask the user to remove the job from their computer's print queue and print again.
5. If the printer shows a paper jam or a "toner low" message, the user should not open the printer. Report it with the printer's name, written on its front label.

Report a broken printer by opening a support ticket that includes the printer name and the message on its screen.
