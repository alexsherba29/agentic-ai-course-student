# Email outage procedure

Use this procedure when users report that email is not working: messages are not arriving, cannot be sent, or the mailbox does not load.

First, check the service status page for email.

If email shows an outage or degraded service:

1. Tell the user it is a known problem that the IT team is already working on.
2. Explain that messages are queued and will be delivered when the service recovers; nothing is lost.
3. Do not open a new ticket for the same outage. Point the user to the status page for updates.

If email shows operational, the problem is probably limited to this user:

1. Ask the user to sign out of the mail app and sign in again.
2. Ask them to try webmail in a browser at https://mail.example.edu.
3. If webmail works but the app does not, remove and re-add the account in the app.
4. If webmail does not work either, open a support ticket with the user's username and the exact error message.
