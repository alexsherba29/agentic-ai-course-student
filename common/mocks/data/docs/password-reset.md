# Password reset procedure

Use this procedure when a user has forgotten their password or their account is locked after too many failed sign-in attempts.

Never ask the user to tell you their old or new password, in chat or in a ticket.

Self-service reset:

1. Go to the password reset portal at https://password.example.edu.
2. Enter the university username (not the email address).
3. Choose to receive a one-time code by text message or to the recovery email address.
4. Enter the code and choose a new password with at least 12 characters.
5. Wait five minutes before signing in again, so the new password reaches all systems.

An account locks for 30 minutes after five failed sign-in attempts. It unlocks on its own; a password reset also unlocks it immediately.

If the user has no access to their recovery phone or email, they must visit the IT help desk in person with a student or staff card. Open a support ticket only if the help desk is closed.
